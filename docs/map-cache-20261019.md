# Stable map identification — 2026-10-19

PitMapManager now identifies a map once per World object and retains it for that world's lifetime. It no longer discards a known map every five seconds. Marker chunk unloading therefore cannot turn all list regions into ???. Map marker reads only inspect loaded blocks. An initially unknown map retries at most once a second until it can be identified; known maps perform no further marker probes, even through an explicit detectMap call.

PlayerESP enable/render/disable no longer resets the shared map cache. Lifecycle session resets consult the world-aware cache instead of forcibly clearing it; same-world corrections and player replacement preserve the identified map. Changing/disconnecting worlds still invalidates it immediately.

run-map-cache-tests.py compiles the actual PitMapManager against controlled world/block APIs. Its 525 checks cover all five maps, repeated same-world accesses after marker unloading, explicit detection calls, no unloaded chunk reads, bounded initial discovery, world transitions/disconnects, and the new combat margin with spawn/sewer exclusions.
